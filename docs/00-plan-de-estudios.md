# Plan de estudio práctico

Objetivo: desempeñarse como consultor técnico-funcional capaz de configurar, diagnosticar, consultar datos y desarrollar soluciones en Finance y Business Central. ChatGPT guía cada laboratorio, sin repetir fundamentos de contabilidad.

| Clase | Tema | Entregable | Estado |

| DYN-01 | F&O: factura proveedor, dimensiones, validación | Diagnóstico + matriz UAT + evidencia | En práctica |
| DYN-02 | F&O: AP, diarios, perfiles de contabilización | Flujo factura → asiento | Pendiente |
| DYN-03 | F&O: sociedades y Account Structures | Pruebas de reglas entre sociedades | Pendiente |
| DYN-04 | F&O: compras, Project Accounting, workflows | Requerimientos y UAT | Pendiente |
| DYN-05 | F&O técnico: AOT, tablas y Data Entities | Mapa técnico de incidente | Pendiente |
| DYN-06 | X++: select/joins, clases, debugging | Código y trazabilidad | Pendiente |
| DYN-07 | Integraciones: OData, APIs, Power Platform | Diseño y pruebas de integración | Pendiente |
| DYN-08 | BC: prueba/sandbox y configuración | Navegación y configuración | Pendiente |
| DYN-09 | BC: tablas, páginas y Page Inspection | Rastreo de factura | Pendiente |
| DYN-10 | BC: VS Code y primera extensión AL | Publicar extensión de prueba | Pendiente |
| DYN-11 | BC: eventos, codeunits, APIs | Extensión funcional con pruebas | Pendiente |

Los programas MB-310, MB-500, MB-800, MB-820 son **referencias de objetivos**, no certificaciones obtenidas.

Ciclo: observar pantalla → realizar acción → comprobar resultado → entender tablas/código → documentar evidencia.
