# Microsoft Dynamics 365 — Consultant & Developer Lab

Laboratorio práctico y público para aprender a configurar, dar soporte, diagnosticar y desarrollar sobre **Dynamics 365 Finance & Operations (F&O)** y **Business Central (BC)**.

**Modalidad:** sesiones guiadas en español, con navegación por pantallas, decisiones de soporte, pruebas funcionales (UAT) y ejercicios técnicos. Se asumen conocimientos previos de contabilidad y procesos ERP. No se pide lectura pasiva de manuales.
